# Elmford simulation

This glossary defines the simulation's time concepts so world rules and
applications use the same language.

## Time

**World day**:
A full calendar day of 24 world-hours.

**World-time pace**:
The relationship between world time and real time. The default target is one
world day per four hours of real-time play.

**Simulation step**:
A fixed quantum by which simulation time advances, independent of how quickly
real time passes.
